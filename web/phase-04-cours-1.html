Le terminal

Jusqu'ici, tout se passait dans l'éditeur du site. À partir de cette phase, tu sors du navigateur : Git et le déploiement se pilotent depuis la ligne de commande. Ce premier cours pose les bases indispensables avant d'attaquer Git lui-même.

Pourquoi la ligne de commande

Un terminal exécute des commandes textuelles plutôt que des clics. Ça semble plus lent au premier abord, mais c'est en réalité l'outil le plus rapide et le plus universel pour naviguer dans des fichiers, lancer des programmes, et — ce qui nous intéresse ici — piloter Git.

Définition

Le terminal (ou shell) est un programme qui lit des commandes textuelles et les exécute. Sur Windows on utilise souvent Git Bash ou PowerShell, sur macOS et Linux le Terminal est intégré.

Se repérer : où suis-je ?

Le terminal travaille toujours dans un dossier courant. Avant de faire quoi que ce soit, il faut savoir où on se trouve et ce qu'il y a autour.

pwd # affiche le chemin du dossier courant ls # liste les fichiers et dossiers ici (dir sur Windows) ls -la # liste aussi les fichiers cachés, avec plus de détails

Se déplacer et créer

cd mon-dossier # entre dans "mon-dossier" cd .. # remonte d'un niveau cd ~ # retourne au dossier personnel mkdir mon-projet # crée un nouveau dossier touch index.html # crée un fichier vide (macOS/Linux)

Manipuler des fichiers

mv ancien.txt nouveau.txt # renomme (ou déplace) cp fichier.txt copie.txt # copie rm fichier.txt # supprime — attention, définitif rm -r dossier # supprime un dossier entier — encore plus définitif
Prudence

Le terminal n'a pas de corbeille. rm supprime immédiatement et définitivement. Avant un rm -r, un ls pour vérifier ce qu'on s'apprête à effacer n'est jamais du temps perdu.

Table de référence

  • pwd — afficher le dossier courant
  • ls — lister le contenu
  • cd <dossier> — se déplacer
  • mkdir <nom> — créer un dossier
  • touch <fichier> — créer un fichier vide
  • mv / cp / rm — déplacer, copier, supprimer
  • clear — nettoyer l'écran du terminal
À retenir
  • Le terminal exécute des commandes textuelles dans un dossier courant, qu'on connaît avec pwd.
  • ls et cd sont les deux commandes qu'on utilise en permanence pour se repérer.
  • mkdir, touch, mv, rm couvrent l'essentiel de la gestion de fichiers.
  • rm est définitif — pas de corbeille en ligne de commande.
