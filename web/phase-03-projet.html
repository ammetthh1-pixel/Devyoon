Ta liste de tâches

Une vraie petite application, sans framework : ajouter une tâche, la marquer terminée, la voir apparaître instantanément. Tout ce que tu as vu dans les trois cours (variables/fonctions, DOM, événements) se retrouve ici.

Objectif

Construis une liste de tâches interactive : un champ pour saisir une tâche, un bouton pour l'ajouter, et une liste qui s'actualise sans rechargement de page. Cette fois, l'éditeur a un troisième onglet : script.js, pour ton JavaScript.

Fonctionnalités attendues

Ajouter — taper une tâche et cliquer sur le bouton l'ajoute à la liste

Champ vidé — après ajout, le champ de saisie redevient vide, prêt pour la tâche suivante

Marquer terminée — cliquer sur une tâche de la liste la barre (ou change son style)

Pas de tâche vide — cliquer sur "Ajouter" sans rien écrire ne doit rien ajouter

Contraintes techniques

  • Écris ton JavaScript dans l'onglet script.js — il est automatiquement exécuté après le chargement de la page
  • Utilise addEventListener pour le bouton d'ajout
  • Crée les nouvelles tâches avec document.createElement et appendChild — pas de HTML écrit en dur pour chaque tâche
  • Pour "marquer terminée", utilise la délégation d'événements vue au cours 3 : un seul écouteur sur la liste, qui regarde l'élément cliqué
Astuce

Reprends directement l'exemple "Assembler le tout" du cours 3 comme point de départ, puis ajoute la logique de délégation du cours 3 pour la mise en terminé.

Critère de réussite

Tu peux ajouter plusieurs tâches à la suite, chacune apparaît dans la liste, le champ se vide après chaque ajout, et cliquer sur une tâche la marque visuellement comme terminée.
