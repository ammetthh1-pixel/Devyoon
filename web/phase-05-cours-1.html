Composants et JSX

Ta liste de tâches en JavaScript pur fonctionnait, mais à mesure qu'une interface grossit, manipuler le DOM à la main devient vite pénible. React propose une autre façon de penser : découper l'interface en composants, et décrire ce qu'on veut afficher plutôt que comment l'obtenir étape par étape.

Pourquoi un framework

En JavaScript pur, chaque changement d'affichage passe par du createElement, appendChild, textContent — du code impératif qui décrit chaque étape. React fonctionne différemment : tu décris à quoi l'interface doit ressembler pour un état donné, et React se charge de mettre à jour le DOM pour que ça corresponde.

Définition

Un framework front-end comme React fournit une façon structurée de construire des interfaces : découper l'UI en composants réutilisables, et laisser la bibliothèque gérer la synchronisation entre les données et ce qui s'affiche.

Un composant, en pratique

Un composant React est simplement une fonction JavaScript qui renvoie ce qui doit s'afficher. Par convention, son nom commence toujours par une majuscule.

function Bienvenue() { return <h1>Bonjour DevYoon</h1>; }

Cette syntaxe qui ressemble à du HTML directement dans du JavaScript s'appelle JSX. Ce n'est pas du HTML — c'est transformé (compilé) en appels JavaScript avant d'être exécuté.

Définition

JSX (JavaScript XML) est une extension de syntaxe qui permet d'écrire des éléments d'interface directement dans du JavaScript. Le navigateur ne comprend pas le JSX nativement — un outil (ici, Babel) le transforme en JavaScript classique avant exécution.

Insérer du JavaScript dans le JSX

Les accolades { } permettent d'insérer n'importe quelle expression JavaScript au milieu du JSX.

function Salutation() { const nom = "Awa"; const heure = new Date().getHours(); return ( <div> <h1>Bonjour {nom}</h1> <p>Il est {heure}h.</p> </div> ); }

Une règle importante : un composant JSX doit toujours renvoyer un seul élément racine (ici, le <div> qui englobe le <h1> et le <p>).

Assembler des composants

Un composant peut en utiliser un autre, exactement comme une balise HTML — c'est le principe de composition, le cœur de React.

function Titre() { return <h1>Mon application</h1>; } function App() { return ( <div> <Titre /> <p>Bienvenue sur mon app React.</p> </div> ); }

Remarque la syntaxe <Titre /> — une balise auto-fermante, exactement comme <img /> en HTML.

Afficher un composant React sur une page

Enfin, on demande à React de prendre le contrôle d'un élément du DOM — traditionnellement une <div id="root"></div> vide — et d'y afficher un composant.

ReactDOM.createRoot(document.getElementById("root")).render(<App />);
Dans cet éditeur

DevYoon charge React, ReactDOM et Babel directement depuis un CDN, sans étape de build (pas de npm, pas de Vite). C'est parfait pour apprendre, mais un vrai projet React en production utilise presque toujours un outil de build — tu le verras si tu continues avec React plus tard.

À retenir
  • Un composant React est une fonction (nom en majuscule) qui renvoie du JSX.
  • Le JSX ressemble à du HTML mais est transformé en JavaScript par Babel avant exécution.
  • Les accolades { } insèrent une expression JavaScript dans le JSX.
  • Un composant doit renvoyer un seul élément racine.
  • Les composants s'assemblent entre eux, comme des balises — c'est la composition.
