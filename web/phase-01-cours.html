Structure & mise en forme

Tu sais maintenant ce qui se passe côté réseau. Cette phase attaque le concret : structurer une page avec du HTML sémantique, puis la mettre en forme avec CSS. C'est la base de tout ce que tu construiras ensuite.

Le squelette d'un document HTML

Une page HTML a toujours la même ossature de départ. Le <head> contient les métadonnées (titre, liens vers le CSS), le <body> contient tout ce qui est visible.

<!DOCTYPE html> <html lang="fr"> <head> <meta charset="UTF-8"> <title>Ma page</title> <link rel="stylesheet" href="style.css"> </head> <body> <!-- contenu visible --> </body> </html>

Les balises sémantiques

Plutôt que d'empiler des <div> partout, le HTML moderne propose des balises qui décrivent le rôle de chaque zone. Un navigateur, un moteur de recherche ou un lecteur d'écran comprennent mieux une page bien structurée.

  • <header> — l'en-tête de la page ou d'une section
  • <nav> — un bloc de navigation
  • <main> — le contenu principal, unique par page
  • <section> — un regroupement thématique de contenu
  • <article> — un contenu autonome (un article, une carte)
  • <footer> — le pied de page
Définition

Le HTML sémantique consiste à choisir des balises qui décrivent le sens du contenu, pas seulement son apparence.

Le modèle de boîte CSS

En CSS, chaque élément est une boîte rectangulaire composée de quatre couches, de l'intérieur vers l'extérieur.

Content → padding (espace intérieur) → border (bordure) → margin (espace extérieur).

.carte { width: 300px; padding: 20px; border: 1px solid #1E2D45; margin: 16px; }

Sélecteurs CSS

Un sélecteur détermine à quels éléments s'applique une règle de style.

/* toutes les balises p */ p { color: #F0F4FF; } /* la classe "carte" */ .carte { border-radius: 10px; } /* l'identifiant unique "hero" */ #hero { padding: 60px; } /* tous les liens à l'intérieur d'un nav */ nav a { text-decoration: none; } /* état au survol */ .btn:hover { opacity: .9; }

Retiens l'essentiel : la classe (.nom) sert pour un style réutilisé sur plusieurs éléments, l'identifiant (#nom) pour un élément unique sur la page.

Typographie et couleurs

Deux propriétés suffisent pour poser une bonne base typographique : font-family pour la police, font-size pour la taille. Pour les couleurs, tu croiseras surtout deux notations.

body { font-family: 'Inter', sans-serif; font-size: 16px; color: #F0F4FF; /* notation hexadécimale */ background: rgb(10, 14, 26); /* notation rgb */ }

Une bonne pratique dès le départ : choisis une ou deux polices maximum, et une palette de 3-4 couleurs cohérentes — c'est exactement ce que fait ce site.

À retenir
  • Le HTML sémantique décrit le sens du contenu, pas seulement son apparence.
  • Chaque élément CSS est une boîte : content, padding, border, margin.
  • Les classes servent aux styles réutilisés, les identifiants aux éléments uniques.
  • Une base typographique cohérente repose sur peu de polices et une palette limitée.
