Quiz — Comment marche le web

Vérifie tes bases avec un quiz de six questions sur le client, le serveur, le DNS, HTTP et l'affichage d'une page.

Objectif

Réponds aux six questions dans l'éditeur. Tu dois sélectionner une réponse pour chaque question, puis cliquer sur Valider.

Notions évaluées

Le rôle du client et du serveur

La résolution DNS et la traduction vers une adresse IP

La méthode HTTP GET

Le code de statut 200 OK

Le rôle du navigateur après réception du HTML

Comment t'y prendre

  1. Après avoir relu le cours, ouvre l'éditeur du quiz.
  2. Lis chaque question et sélectionne une seule réponse.
  3. Clique sur Valider pour voir ton résultat.
  4. Corrige les réponses incorrectes et valide à nouveau jusqu'à obtenir 6/6.
Conseil

Si une réponse te semble difficile, retourne au cours et relis la frise des six étapes avant de retenter le quiz.

Critère de réussite

La phase est validée lorsque les six réponses sont correctes. Si tu es connecté, cette validation est enregistrée dans ton tableau de bord.
