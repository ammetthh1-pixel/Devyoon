Le DOM

Le langage posé, place à ce qu'il permet vraiment de faire sur le web : lire et modifier une page déjà affichée. C'est le DOM qui rend ça possible — et c'est le pont entre ton HTML et ton JavaScript.

Qu'est-ce que le DOM

Quand le navigateur charge une page, il ne garde pas juste le texte HTML — il construit une représentation en mémoire sous forme d'arbre, où chaque balise devient un objet manipulable. C'est cet arbre que JavaScript lit et modifie.

Définition

Le DOM (Document Object Model) est la représentation en mémoire d'une page HTML sous forme d'arbre d'objets. Modifier le DOM modifie ce qui s'affiche à l'écran, immédiatement, sans recharger la page.

Chaque balise HTML devient un nœud de cet arbre, accessible et modifiable depuis JavaScript.

Sélectionner un élément

document.querySelector() est la méthode la plus polyvalente : elle accepte n'importe quel sélecteur CSS et renvoie le premier élément trouvé. querySelectorAll() renvoie tous les éléments correspondants.

// Un seul élément (le premier trouvé) const titre = document.querySelector("h1"); const bouton = document.querySelector("#mon-bouton"); // par id const carte = document.querySelector(".carte"); // par classe // Tous les éléments correspondants (une NodeList, proche d'un tableau) const toutesLesCartes = document.querySelectorAll(".carte"); toutesLesCartes.forEach(c => console.log(c));

Tu croiseras aussi getElementById() et getElementsByClassName(), plus anciennes — querySelector/querySelectorAll suffisent dans la quasi-totalité des cas et sont plus lisibles.

Lire et modifier le contenu

Deux propriétés reviennent tout le temps : textContent pour du texte simple, innerHTML quand on a besoin d'insérer du HTML.

const titre = document.querySelector("h1"); titre.textContent = "Nouveau titre"; // remplace le texte const carte = document.querySelector(".carte"); carte.innerHTML = "<strong>Important</strong>"; // insère du HTML
Pourquoi préférer textContent

innerHTML interprète son contenu comme du HTML — si ce contenu vient d'une saisie utilisateur non contrôlée, c'est une porte ouverte à l'injection de code malveillant. Par défaut, utilise textContent pour du texte ; réserve innerHTML aux cas où tu contrôles vraiment ce qui est inséré.

Modifier styles et classes

Plutôt que de manipuler l'attribut style directement, la bonne pratique est de basculer des classes CSS avec classList — le style reste dans le CSS, JavaScript ne fait qu'activer ou désactiver un état.

const carte = document.querySelector(".carte"); carte.classList.add("active"); // ajoute la classe carte.classList.remove("active"); // la retire carte.classList.toggle("active"); // bascule (ajoute si absente, retire si présente) carte.classList.contains("active"); // true / false

Créer et supprimer des éléments

On peut aussi construire de nouveaux éléments entièrement depuis JavaScript, puis les insérer dans la page.

const liste = document.querySelector("ul"); const item = document.createElement("li"); item.textContent = "Nouvel élément"; liste.appendChild(item); // ajoute à la fin de la liste // Pour supprimer : item.remove();
À retenir
  • Le DOM représente la page en mémoire sous forme d'arbre — JavaScript le lit et le modifie.
  • querySelector / querySelectorAll sélectionnent des éléments avec n'importe quel sélecteur CSS.
  • textContent pour du texte simple, innerHTML seulement quand c'est nécessaire (risque d'injection).
  • classList.add/remove/toggle pour changer l'apparence — jamais l'attribut style directement.
  • createElement + appendChild construisent de nouveaux éléments ; .remove() les enlève.
