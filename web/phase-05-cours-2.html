Les props

Un composant qui affiche toujours le même contenu n'est pas très utile. Les props permettent de lui transmettre des données depuis l'extérieur — exactement comme un attribut HTML, mais avec n'importe quelle valeur JavaScript.

Transmettre une donnée à un composant

Une prop (property) se transmet en l'écrivant comme un attribut sur la balise du composant. Le composant la reçoit en paramètre de sa fonction.

function Carte(props) { return <div className="carte">{props.titre}</div>; } function App() { return ( <div> <Carte titre="Première carte" /> <Carte titre="Deuxième carte" /> </div> ); }
Définition

Les props sont les données qu'un composant parent transmet à un composant enfant. Elles sont en lecture seule : un composant ne doit jamais modifier ses propres props, seulement les lire.

Déstructurer les props

Plutôt que d'écrire props.titre, props.description partout, on déstructure directement dans les paramètres de la fonction — plus court, plus lisible.

// Version avec props.xxx function Carte(props) { return <h3>{props.titre}</h3>; } // Version déstructurée — équivalente, plus lisible function Carte({ titre, description }) { return ( <div> <h3>{titre}</h3> <p>{description}</p> </div> ); }

Transmettre un objet entier

Une prop peut être n'importe quelle valeur JavaScript — pas seulement du texte. C'est très courant de transmettre un objet complet, puis de le déstructurer côté composant.

function Profil({ utilisateur }) { return ( <div> <h3>{utilisateur.nom}</h3> <p>{utilisateur.role}</p> </div> ); } function App() { const awa = { nom: "Awa", role: "Étudiante" }; return <Profil utilisateur={awa} />; }

Remarque les accolades autour de awa : dès qu'on transmet une valeur JavaScript (et pas juste du texte entre guillemets), on utilise { } plutôt que " ".

Props ou état : quelle différence

C'est une confusion fréquente en débutant avec React. Les deux servent à stocker des données utilisées dans le rendu, mais leur origine et leur comportement diffèrent totalement.

Définition

Les props viennent du parent, en lecture seule, et changent uniquement si le parent les redonne différemment. L'état (vu au cours 3) appartient au composant lui-même, qui peut le modifier — c'est ce qui rend un composant vraiment interactif.

À retenir
  • Les props transmettent des données d'un composant parent vers un composant enfant.
  • Elles s'écrivent comme des attributs (<Carte titre="..." />) et se lisent en paramètre de la fonction.
  • Déstructurer les props ({ titre, description }) rend le code plus lisible.
  • Une prop peut être n'importe quelle valeur JS — texte, nombre, objet, tableau — avec des accolades dès que ce n'est pas du texte brut.
  • Les props sont en lecture seule ; l'état (cours 3) est ce qu'un composant peut modifier lui-même.
