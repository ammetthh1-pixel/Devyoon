Quiz Git & dépôt réel

Cette phase a deux volets, et c'est volontaire. Git ne s'exécute pas dans un navigateur — l'éditeur de DevYoon ne peut donc pas te faire taper de vraies commandes Git. Le quiz valide ta phase sur le site ; le dépôt réel est ce qui compte vraiment pour la suite de ta pratique.

Volet 1 — Le quiz (validé sur le site)

Huit questions sur le terminal et Git : commandes de base, cycle add/commit, .gitignore, publication sur GitHub. C'est ce quiz qui marque la Phase 04 comme terminée dans ton tableau de bord.

Notions évaluées

Navigation en ligne de commande (cd, ls, pwd)

Le cycle add → commit

Le rôle de .gitignore

Publier un dépôt local sur GitHub

Volet 2 — Le vrai dépôt (sur ta machine, non noté ici)

La compétence réelle de cette phase se pratique en dehors du site. Voici ce qu'il faut faire, dans l'ordre :

  1. Installe Git si ce n'est pas déjà fait, puis configure ton nom et ton email (git config --global user.name "...")
  2. Reprends ta page personnelle de la Phase 01 (ou ta liste de tâches de la Phase 03), et transforme son dossier en dépôt Git (git init)
  3. Ajoute un fichier .gitignore pertinent, fais un premier commit
  4. Crée un dépôt vide sur GitHub, connecte-le avec git remote add origin, puis git push
  5. Vérifie que ton code est bien visible sur la page GitHub de ton dépôt
Pourquoi ce n'est pas noté automatiquement

Valider un vrai dépôt GitHub demanderait d'te connecter à ton compte GitHub personnel depuis le site — une fonctionnalité qui n'existe pas encore ici. Ce volet reste donc auto-dirigé : c'est un vrai jalon pour ta pratique, mais pas un pré-requis technique pour débloquer la Phase 05.

Critère de réussite

Le quiz est validé à 8/8. Et, idéalement, un vrai dépôt existe sur ton compte GitHub avec au moins deux commits d'historique — ta première trace de travail versionné.
