Simulateur d'API REST

Un vrai serveur Express ne peut pas tourner dans cet éditeur — il faudrait un vrai processus Node.js, que le navigateur ne peut pas exécuter. Ce projet simule donc les quatre opérations CRUD d'une API en JavaScript pur, avec les mêmes noms et la même logique qu'un vrai serveur Express.

Objectif

Complète quatre fonctions qui imitent les routes d'une API REST de tâches — getTaches, creerTache, modifierTache, supprimerTache — reliées à une petite interface déjà fournie qui affiche le résultat de chaque "requête".

Les quatre fonctions à compléter

getTaches() — équivalent de GET /api/taches, renvoie le tableau complet

creerTache(texte) — équivalent de POST /api/taches, ajoute et renvoie la nouvelle tâche

modifierTache(id, terminee) — équivalent de PUT /api/taches/:id

supprimerTache(id) — équivalent de DELETE /api/taches/:id

Contraintes techniques

  • Ne modifie pas l'interface déjà fournie (les boutons et la zone d'affichage) — complète seulement les quatre fonctions
  • creerTache doit utiliser et incrémenter prochainId, exactement comme l'exemple du cours 3
  • modifierTache doit retrouver la tâche par son id dans le tableau, comme le ferait une vraie requête WHERE id = ...
Le lien avec un vrai serveur

Si tu reprends ce code et que tu l'places dans des routes Express (app.get("/api/taches", (req, res) => res.json(getTaches())), etc.), tu as déjà un vrai serveur fonctionnel. La logique ne change pas — seul le "transport" (HTTP au lieu d'un clic de bouton) change.

Critère de réussite

Chaque bouton de l'interface déclenche la bonne opération et affiche un résultat cohérent dans la zone de sortie — une création apparaît dans la liste suivante, une modification change bien l'état "terminée", une suppression fait disparaître la tâche des listes suivantes.
