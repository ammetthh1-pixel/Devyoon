Les bases de JavaScript

Le HTML donne la structure, le CSS donne l'apparence. JavaScript, lui, donne le comportement : c'est le seul des trois qui peut réagir, calculer, décider. Cette phase est en trois parties — ce premier cours pose le langage, les deux suivants passent au DOM et aux événements.

Ce que JavaScript ajoute

Une page en HTML/CSS pur est figée : une fois chargée, rien ne change sans recharger la page. JavaScript s'exécute après le chargement et peut réagir à ce que fait la personne qui visite le site — un clic, une saisie, un défilement — et modifier la page en conséquence, sans rechargement.

Définition

JavaScript est un langage de programmation exécuté directement dans le navigateur. Il permet de lire et modifier une page (via le DOM, vu au cours 2), de réagir à des événements (vu au cours 3), et de faire des calculs ou de la logique comme n'importe quel langage.

Déclarer une variable : let et const

Une variable stocke une valeur pour la réutiliser. En JavaScript moderne, on utilise let pour une valeur qui va changer, et const pour une valeur qui ne changera plus après sa déclaration.

let score = 0; score = score + 10; // autorisé : "let" peut être réassigné const nomSite = "DevYoon"; // nomSite = "Autre"; -> erreur : une const ne se réassigne pas
Et le mot-clé var ?

Tu croiseras encore var dans du vieux code — c'est l'ancienne façon de déclarer une variable, avec des règles de portée plus permissives et souvent source de bugs. Dans du code écrit aujourd'hui, on utilise uniquement let et const.

Les types de données

Comme en Python, le type d'une variable JavaScript est déduit de sa valeur. Les types de base :

const age = 19; // number const ville = "Thiès"; // string const estEtudiant = true; // boolean const langages = ["HTML", "CSS", "JS"]; // array const profil = { nom: "Awa", age: 22 }; // object let resultat; // undefined (pas encore de valeur)

Les tableaux (array) et les objets (object) sont les équivalents des listes et dictionnaires Python — tu les retrouveras partout dès qu'on touchera au DOM.

Comparaisons et conditions

JavaScript propose deux opérateurs d'égalité : == et ===. En pratique, on utilise presque toujours ===.

Pourquoi === et pas ==

== convertit les types avant de comparer ("5" == 5 vaut true, ce qui surprend souvent). === compare la valeur et le type, sans conversion cachée — c'est le comportement prévisible qu'on veut presque toujours.

const note = 14; if (note >= 16) { console.log("Très bien"); } else if (note >= 10) { console.log("Admis"); } else { console.log("Insuffisant"); }

Boucles

Deux formes reviennent le plus souvent : for classique pour compter, for...of pour parcourir directement les éléments d'un tableau.

for (let i = 0; i < 5; i++) { console.log(i); // 0 1 2 3 4 } const fruits = ["mangue", "banane", "orange"]; for (const fruit of fruits) { console.log(fruit); }

Fonctions

Deux syntaxes courantes pour écrire une fonction — la déclaration classique et la fonction fléchée, plus courte, très utilisée dans le code moderne (et dans les gestionnaires d'événements du cours 3).

// Déclaration classique function moyenne(notes) { const somme = notes.reduce((a, b) => a + b, 0); return somme / notes.length; } // Fonction fléchée équivalente const moyenneFlechee = (notes) => { const somme = notes.reduce((a, b) => a + b, 0); return somme / notes.length; }; console.log(moyenne([12, 15, 9, 18])); // 13.5
À retenir
  • On déclare avec let (valeur modifiable) ou const (valeur fixe) — jamais var dans du code neuf.
  • Les types de base : number, string, boolean, array, object, undefined.
  • === compare valeur et type sans conversion cachée — à préférer à ==.
  • for compte, for...of parcourt directement les éléments d'un tableau.
  • Les fonctions fléchées (() => {}) sont la syntaxe la plus courante en JavaScript moderne.
