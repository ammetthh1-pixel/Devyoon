Responsive & mise en page avancée

Ta page personnelle marchait bien sur ton écran — mais sur un téléphone ? Cette phase te donne les deux outils qui construisent 90% des mises en page modernes : Flexbox et Grid, plus la technique qui rend tout ça adaptatif : les media queries.

Pourquoi le responsive

La majorité du trafic web passe par mobile. Une page qui n'est pensée que pour un écran large casse dès qu'elle est consultée sur un téléphone : texte trop petit, éléments qui débordent, boutons impossibles à toucher. Le responsive design consiste à construire une mise en page qui s'adapte à la taille de l'écran, plutôt que d'en imposer une seule.

Définition

Une mise en page responsive réorganise automatiquement son contenu selon la largeur de l'écran — sans qu'il soit nécessaire de créer une page différente pour chaque appareil.

Flexbox : aligner sur un axe

Flexbox distribue des éléments le long d'un axe principal (par défaut horizontal). C'est l'outil idéal pour aligner une barre de navigation, centrer un bloc, ou distribuer des cartes sur une ligne.

.cartes { display: flex; gap: 20px; justify-content: space-between; /* répartition sur l'axe principal */ align-items: stretch; /* alignement sur l'axe secondaire */ flex-wrap: wrap; /* passe à la ligne si ça ne rentre plus */ }

Les propriétés à connaître

  • display: flex — active Flexbox sur le conteneur
  • justify-content — répartition le long de l'axe principal (flex-start, center, space-between...)
  • align-items — alignement sur l'axe perpendiculaire
  • gap — espace entre les éléments, sans marges bricolées
  • flex-wrap: wrap — indispensable pour que ça reste responsive

Grid : organiser en deux dimensions

Là où Flexbox aligne sur un axe, Grid découpe l'espace en lignes et colonnes à la fois. C'est l'outil naturel pour une grille de cartes, une mise en page de type magazine, ou une structure page complète (en-tête / contenu / barre latérale / pied de page).

Une grille 3 colonnes × 2 lignes — la structure exacte d'une section "nos services" à trois cartes.

.cartes { display: grid; grid-template-columns: repeat(3, 1fr); /* 3 colonnes égales */ gap: 20px; }

L'unité fr (fraction) répartit l'espace disponible proportionnellement — repeat(3, 1fr) crée trois colonnes de largeur égale, sans calcul de pourcentage à la main.

Media queries : adapter selon la largeur

Une media query applique des règles CSS uniquement si une condition sur l'écran est vraie — le plus souvent, une largeur maximale ou minimale.

/* Par défaut : mise en page pensée pour le mobile */ .cartes { display: flex; flex-direction: column; } /* À partir de 768px de large : bascule en ligne */ @media (min-width: 768px) { .cartes { flex-direction: row; } }
Approche recommandée : mobile-first

On écrit d'abord le style pour petit écran, puis on ajoute des media queries avec min-width pour enrichir la mise en page à mesure que l'écran s'agrandit — plutôt que l'inverse.

Points de rupture courants

  • 480px — téléphones
  • 768px — tablettes
  • 1024px — petits ordinateurs
À retenir
  • Flexbox aligne des éléments sur un axe — idéal pour une barre de nav ou une ligne de cartes.
  • Grid organise en lignes et colonnes — idéal pour une grille ou une structure de page.
  • Les media queries appliquent des styles selon la largeur de l'écran.
  • L'approche mobile-first construit d'abord pour petit écran, puis enrichit vers le grand écran.
