Un site vitrine responsive

Une petite entreprise fictive te demande une page vitrine. L'objectif : qu'elle soit aussi lisible sur un téléphone que sur un grand écran, avec une vraie mise en page (pas juste du texte empilé).

Objectif

Construis une page vitrine à une page (index.html + style.css) pour une entreprise ou une activité de ton choix (café, atelier de réparation, cours de soutien, ce que tu veux), avec une mise en page qui se réorganise proprement du mobile au grand écran.

Sections attendues

En-tête avec navigation — un menu avec des liens vers les sections de la page

Nos services — au moins 3 cartes présentant chacune une offre ou un produit

Contact — coordonnées ou lien mailto

Pied de page

Contraintes techniques

  • Les cartes de la section "Nos services" doivent utiliser Flexbox ou Grid — pas de positionnement manuel
  • Ajoute au moins une media query qui change la mise en page selon la largeur de l'écran
  • Sur petit écran, les cartes doivent s'empiler en une seule colonne ; sur écran large, elles s'affichent côte à côte
  • Utilise l'aperçu mobile de l'éditeur (icône téléphone) pour vérifier concrètement le rendu, pas seulement en réduisant la fenêtre
Astuce

Commence par écrire le CSS comme si l'écran était toujours petit (colonne unique), puis ajoute la media query qui bascule en ligne à partir d'une largeur donnée — c'est l'approche mobile-first vue dans le cours.

Critère de réussite

En basculant l'aperçu entre desktop et mobile, la mise en page change réellement de forme (les cartes passent d'une ligne à une colonne, ou inversement) — pas seulement la taille du texte.
