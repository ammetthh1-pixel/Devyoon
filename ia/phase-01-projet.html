Trois scripts de données

Trois mini-automatisations, chacune sur une donnée déjà fournie dans le script — pensées comme si elles venaient d'un fichier ou d'une API, pour se concentrer sur le traitement plutôt que sur la connexion réseau.

Objectif

Écris trois scripts Python séparés, chacun autonome, qui manipulent des données déjà présentes dans le fichier de départ (JSON, fichier virtuel, liste de dictionnaires) — exactement le type de traitement qu'on ferait après avoir reçu une réponse d'API ou lu un fichier.

Pourquoi les données sont déjà dans le code

Pyodide s'exécute entièrement dans ton navigateur, sans accès réseau libre — impossible d'appeler une vraie API depuis cet éditeur. Les données sont donc fournies telles quelles, comme si elles venaient d'y être récupérées : le travail à faire (parser du JSON, lire un fichier, filtrer une liste) est identique à ce que tu ferais avec une vraie API.

Les trois scripts

1. Villes et population

Une chaîne JSON contient une liste de villes avec leur population. Charge-la avec json.loads(), puis calcule la population totale et trouve la ville la plus peuplée.

2. Fichier de notes

Écris un petit dictionnaire de notes dans un fichier avec open(..., "w"), puis relis ce fichier pour calculer et afficher la moyenne.

3. Filtrage d'employés

À partir d'une liste de dictionnaires représentant des employés, filtre ceux qui sont actifs et affiche leur nombre ainsi que leurs noms.

Consignes

Utilise le module json pour le script 1

Utilise with open(...) as f: pour l'écriture et la lecture dans le script 2

Affiche un résultat clair et lisible pour chaque script

Critère de réussite

Chacun des trois scripts s'exécute sans erreur et affiche le bon résultat pour les données fournies.
