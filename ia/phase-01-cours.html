Manipulation de données

Tes scripts de la Phase 00 travaillaient sur des données que tu avais écrites toi-même dans le code. En vrai, les données viennent le plus souvent de l'extérieur : un fichier, une API. Cette phase t'apprend à aller les chercher, les lire et les transformer.

Le format JSON

JSON (JavaScript Object Notation) est le format que la quasi-totalité des API utilisent pour échanger des données. Il ressemble beaucoup aux dictionnaires et listes Python — ce n'est pas un hasard, la correspondance est presque directe.

Définition

JSON représente des données structurées (objets, listes, textes, nombres) sous forme de texte, lisible aussi bien par une machine que par un humain.

# En JSON (texte) { "nom": "Awa", "age": 22, "langages": ["Python", "JavaScript"] } # Le même contenu, une fois chargé en Python, devient : {'nom': 'Awa', 'age': 22, 'langages': ['Python', 'JavaScript']}

En Python, le module json fait la conversion dans les deux sens : json.loads() transforme du texte JSON en dictionnaire/liste Python, json.dumps() fait l'inverse.

import json texte = '{"nom": "Awa", "age": 22}' donnees = json.loads(texte) # -> dictionnaire Python print(donnees["nom"]) # Awa

Lire et écrire des fichiers

Avant de parler d'API, la donnée la plus simple à manipuler reste le fichier. Python ouvre un fichier avec open(), et le mot-clé with garantit qu'il se referme correctement même en cas d'erreur.

# Écrire dans un fichier with open("notes.txt", "w") as f: f.write("Awa: 16\n") f.write("Moussa: 12\n") # Lire un fichier ligne par ligne with open("notes.txt") as f: for ligne in f: print(ligne.strip())
Définition

Le bloc with open(...) as f: ouvre un fichier pour la durée du bloc indenté, puis le referme automatiquement à la sortie — même si une erreur survient à l'intérieur.

Consommer une API

Une API renvoie généralement des données en JSON en réponse à une requête HTTP — exactement le mécanisme vu en Phase 00 du parcours Web, mais appelé depuis du code plutôt que depuis un navigateur. En Python, la bibliothèque requests simplifie cet appel.

import requests reponse = requests.get("https://api.exemple.com/villes") donnees = reponse.json() # conversion automatique en dict/list Python for ville in donnees: print(ville["nom"])

Le cycle complet

  • Le programme envoie une requête GET à une adresse (une API)
  • Le serveur répond avec des données en JSON
  • .json() transforme cette réponse en structures Python utilisables
  • Le programme parcourt et traite ces données comme n'importe quelle liste ou dictionnaire

Transformer des données

Une fois les données chargées (fichier ou API), le travail habituel consiste à les filtrer, les compter, ou les reformater — les mêmes outils que la Phase 00 (boucles, conditions, dictionnaires) s'appliquent directement.

eleves = [ {"nom": "Awa", "note": 16}, {"nom": "Moussa", "note": 9}, {"nom": "Fatou", "note": 14} ] # Filtrer : garder seulement les admis admis = [e for e in eleves if e["note"] >= 10] print(admis)
À retenir
  • JSON est le format d'échange de données le plus courant sur le web — proche des dict/list Python.
  • json.loads() / json.dumps() convertissent entre texte JSON et objets Python.
  • with open(...) as f: lit ou écrit un fichier en le refermant automatiquement.
  • requests.get(url).json() récupère et convertit la réponse d'une API en une seule ligne.
  • Une fois chargées, les données se manipulent avec les outils déjà connus : boucles, conditions, filtres.
