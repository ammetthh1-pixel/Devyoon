Quatre scripts de logique

Quatre petits problèmes, quatre petits scripts Python. Rien de spectaculaire — juste de quoi vérifier que les bases (variables, conditions, boucles, fonctions, listes) sont vraiment acquises avant d'avancer.

Objectif

Écris quatre scripts Python séparés, un par problème ci-dessous. Chaque script doit être autonome, s'exécuter sans erreur, et afficher un résultat clair dans la console.

Les quatre problèmes

1. Pair, impair ou multiple de 3

Pour chaque nombre de 1 à 50 : affiche "Fizz" s'il est multiple de 3, "Buzz" s'il est pair, sinon le nombre lui-même.

2. Moyenne et mention

À partir d'une liste de notes, calcule la moyenne avec une fonction, puis affiche une mention : "Insuffisant" (<10), "Admis" (10-15), "Très bien" (>15).

3. Le mot le plus long

Dans une liste de mots donnée, trouve et affiche le mot le plus long — sans utiliser de fonction déjà toute faite pour ça, en le faisant "à la main" avec une boucle.

4. Compteur de lettres

Pour un mot donné, construis un dictionnaire qui compte combien de fois chaque lettre apparaît, puis affiche-le.

Consignes

Un fichier .py par problème, avec un nom clair (ex. fizzbuzz.py)

Au moins une fonction utilisée dans les problèmes 2, 3 et 4

Teste chaque script avec au moins trois jeux de données différents

Un affichage lisible dans la console pour chaque résultat

Exemple de sortie attendue (problème 2)

Moyenne calculée : 13.5 → Mention : Admis

Critère de réussite

Chacun des quatre scripts tourne sans erreur et donne le bon résultat sur tous les cas de test que tu lui donnes — y compris des cas un peu piégeux (liste vide, mot avec des lettres répétées, nombre négatif).
