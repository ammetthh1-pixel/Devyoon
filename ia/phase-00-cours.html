Bases de la programmation

Avant de parler d'agents et de modèles de langage, il faut savoir écrire du code qui réfléchit correctement. Cette phase pose les fondations en Python — le langage qu'on utilisera pour tout le reste du parcours IA.

Variables et types

Une variable est un nom qui pointe vers une valeur en mémoire. Tu peux l'imaginer comme une boîte étiquetée : l'étiquette est le nom, le contenu est la valeur.

Définition

Une variable associe un nom à une valeur. En Python, pas besoin de préciser le type à l'avance — il est déduit automatiquement de la valeur affectée.

Le nom pointe vers une valeur stockée en mémoire — ici un entier et une chaîne de caractères.

age = 19 # int taille = 1.75 # float ville = "Thiès" # str actif = True # bool

Conditions

Une condition permet à un programme de choisir un chemin selon une situation, avec if, elif et else.

note = 14 if note >= 16: print("Très bien") elif note >= 10: print("Admis") else: print("Insuffisant")

Boucles

Une boucle répète une action. for parcourt une séquence connue, while répète tant qu'une condition reste vraie.

for i in range(5): print(i) # 0 1 2 3 4 compteur = 0 while compteur < 3: print("tour", compteur) compteur += 1

Fonctions

Une fonction regroupe un bloc de code réutilisable. Elle reçoit des paramètres en entrée et peut renvoyer un résultat avec return.

def moyenne(notes): return sum(notes) / len(notes) resultat = moyenne([12, 15, 9, 18]) print(resultat) # 13.5

Structures de données

Les listes stockent des éléments ordonnés, les dictionnaires associent des clés à des valeurs — ce sont les deux structures que tu utiliseras le plus souvent.

fruits = ["mangue", "banane", "orange"] print(fruits[0]) # "mangue" eleve = {"nom": "Awa", "note": 16} print(eleve["nom"]) # "Awa"
À retenir
  • Une variable associe un nom à une valeur, dont le type est déduit automatiquement.
  • Les conditions (if/elif/else) font choisir un chemin au programme.
  • Les boucles (for/while) répètent une action.
  • Les fonctions regroupent du code réutilisable avec des paramètres et un retour.
  • Les listes et les dictionnaires sont les deux structures de données de base à maîtriser.
